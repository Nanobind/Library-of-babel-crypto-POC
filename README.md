# Library-of-babel-crypto-POC


A proof of concept software the encrypts a file utilizing a text scrambling program to obfuscate a inputted message. 

This code is inspired by the library of babel book, where an endless library full of scrambled books exist.

This scrambling text idea was taken in thos proof of concept. 

a message is inputted into the secret creator file which splits this message into its individual letters, obfuscating these letters 
3 times over with ascii and inputting a random selection of values that is placed inbetween each of these numbers before it is then placed into a file. 
The goal of this proof of concept is to eventually have multiple scrambled messages placed on the singular file each having their own equivilent descrambler 
file known to whoever is relavent to the file. 

This concept is still in its early development.
